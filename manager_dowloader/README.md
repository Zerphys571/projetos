##  Inicialização Automática no Windows

Para que o **Organizador de Downloads** comece a monitorar a pasta assim que você ligar o computador:

1.  Utilize as teclas `Win + R` no teclado para abrir a janela **Executar**.
2.  Digite `shell:startup` e pressione **Enter** (isso abrirá a pasta de Inicialização do Windows).
3.  Cole um atalho do arquivo `organizer.exe` dentro dessa pasta.

Agora na próxima vez que o sistema iniciar, o programa será executado em segundo plano e exibirá a notificação de confirmação.
